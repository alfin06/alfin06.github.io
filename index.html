NeurIPS 2025

Can Agents Fix Agent Issues?

Alfin Wijaya Rahardja* et al. · *Co-first author

The 39th Annual Conference on Neural Information Processing Systems (NeurIPS 2025)

Paper arXiv Code Leaderboard

LLM-based agent systems are prone to their own unique bugs. Recent SE agents do well on traditional software, but how well do they handle issues in agent systems? We manually analyzed 201 real-world agent issues and built AgentIssue-Bench to evaluate state-of-the-art SE agents, finding very low resolution rates (0.67%–4.67%).

Preprint 2026

AgentBug-Smith: Automatically Reproducing Real-World Harness Bugs in Agentic Systems

Yiming Cheng, Alfin Wijaya Rahardja, Mengshi Zhang, Zihao Chen, Zhenpeng Chen, Yiling Lou

arXiv preprint, September 2026

arXiv Code Live-harness bench

Harness bugs in agentic systems are hard for today's software agents to repair, and existing benchmarks hold only a small, fixed set of them that took hundreds of human hours to build. AgentBug-Smith automatically discovers and reproduces real-world harness bugs from open-source agentic systems, outperforming reproduction techniques designed for general software. Running it in the wild produced Live-Harness-Bench, a live benchmark of 200 reproducible harness bugs that we use both to evaluate software agents and as a knowledge base for distilling repair skills that improve them.
